Johny Kvsky DevTools

Small browser-based tools for working with common developer data formats.

GitHub

UUID Generator

Generate secure UUID v4 / v7 values, validate UUID v1-8 strings, and inspect time details for time-based UUIDs.

Timestamp Converter

Convert Unix timestamps and human-readable dates, including timezone-aware date entries, locally in your browser.

JSON Formatter

Validate, format, minify, clean, wrap, and copy JSON output with syntax highlighting.

JSON Compare

Validate and compare two JSON documents with formatted output, highlighted differences, and a change list.

Base64 Encoder / Decoder

Encode and decode Base64 strings locally with live linked encoded and decoded panels.

JWT Encoder / Decoder

Decode JWTs, inspect time claims, verify signatures, and encode unsigned, HMAC, RSA, or ECDSA signed tokens locally.
